# Neural Grid V88.8 — six-panel implementation specification

Editable Figma component sheet: https://www.figma.com/design/c6tXpoAxbJNEUca397jCkL

The connected Full Figma seat was used to create six scoped HUD color variables and three reusable components: side panel 310.5×484, bottom panel 414×216, and connector card 288×38. Native Figma Specs remained disabled on the plan; this Markdown document is the implementation specification. The Figma sheet supports, but does not replace, the working code.

The header strip is 42 px high, with 10–14 px technical typography. Desktop grid gaps remain 10 px. At 1714×864, side panels keep their V88.7 top and 484 px height but narrow from 414 to 310.5 px; the right panel remains flush with the old right edge. Bottom panels retain 414 px width and y=850 bottom; height changes from 270 to 216 px. At 1101–1500 px, side panels use the full grid width to prevent cramped labels. Below 1101 px, the V88.7 two-column tablet grid is preserved for usability.

## Component and state rules

- Connector cards use one same-origin icon registry (`v88-icons.js`) shared with the activity feed and station table. Status comes from the unchanged connector registry. Higgsfield is a visual-only, unconfigured card; it has no session or telemetry permissions. Truck Scanner remains in the underlying registry and is never relabeled in historical events.
- Feed rows show only normalized accepted GitHub events, in reverse chronological order, with verified timestamps, run IDs, status color, and the shared icon. Fixture mode carries a persistent warning.
- System Status labels current active workflows separately from completed and failed history. No synthetic performance measures appear.
- Event Flow plots unique accepted GitHub events against real timestamps. The SVG circles expose titles with run and phase. Additional services are not plotted without accepted telemetry.
- Station Metrics shows `—` for unavailable CPU/memory and zero accepted events for the unintegrated services. Higgsfield does not imply a connection.
- Connection Map displays the configured GitHub–gateway–viewer route, with a dashed path unless a live authenticated session and accepted event exist. The four other service nodes are visibly dormant and unlinked. No route conveys execution permissions.
